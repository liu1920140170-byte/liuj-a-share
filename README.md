# 聪明钱复盘台 · A股（Smart Money · Wyckoff Review）

输入一个股票代码，自动用**威科夫理论（Wyckoff Method）**复盘它的走势：
判定处于吸筹/派发/上涨/下跌的哪个阶段、识别关键事件（Spring、UTAD、SOS、LPS…）、
计算关键支撑压力位，并给出**带止损止盈和仓位的买卖建议**。

- 纯 Python 标准库实现，**不需要 pip 安装任何依赖**
- 命令行 + 本地网页（K线图 + 事件标注 + 决策面板）两种用法
- 数据源：东方财富（主）/ 腾讯财经 / 新浪财经（备），任一可用即可出结果
- 全程中文输出，附带判断依据、失效条件和风险提示

## 二、它在算什么（判定逻辑，全部可追溯）

### 1. 结构识别

| 步骤 | 做法 |
| --- | --- |
| 交易区间 | 枚举「结束位置 × 长度」窗口，要求横向度好（回归斜率小）、箱体宽度 3.5%~40%、上下沿被反复触碰、收盘价集中在箱体中部，综合打分取最优 |
| 趋势结构 | 近 60 根K线回归斜率（以 ATR 归一化）+ MA20/MA60 排列，输出向上/向下/横盘 |
| 关键价位 | 区间上下沿（冰线 Ice / 溪流 Creek）、Spring/UT 高低点、摆动高低点、MA20/60/120、一年最高最低，按触碰次数与新鲜度打分，合并且去重 |

### 2. 威科夫事件（自动识别，带量比与评分）

- **吸筹侧**：PS 初次支撑、SC 抛售高潮、AR 自动反弹、ST 二次测试、Spring 弹簧、Shakeout 震仓、Test 缩量测试、SOS 强势信号、LPS 最后支撑点、BU 回抽确认
- **派发侧**：BC 买入高潮、UT 上冲失败、UTAD 派发后上冲失败、SOW 弱势信号、LPSY 最后供给点
- **VSA 量价**：无供给、无需求、停止量、需求进场、供给进场、放量滞涨（吸收）、轻松移动、量能枯竭

每个事件都给出：日期、价格、量比（相对 20 日均量）、0~100 评分、多空方向和中文解释。

### 3. 阶段判定

把「区间形成前的走势、区间内相对位置、涨跌量比、近期事件、均线排列、大盘环境」量化成吸筹分与派发分，
据此判定：

```
吸筹 Accumulation（A 停止下跌 / B 建仓震荡 / C 测试震仓 / D 区间走强 / E 突破）
派发 Distribution（A 停止上涨 / B 派发震荡 / C 上冲失败 / D 区间走弱 / E 破位）
上涨 Markup / 下跌 Markdown / 结构不明 Unknown
```

两个关键的「反吹牛」设计：

- **时间衰减**：只有最近 35 根K线内的信号才算「正在发生」，更早的只作背景；决策评分里信号按距今根数衰减
- **跟随验证**：偏多信号出现后价格却跌回信号位下方 → 该信号权重直接降到 25%，不算数

### 4. 买卖决策

多空评分 → 动作（买入 / 观望等待 / 持有观察 / 减仓 / 卖出回避），并给出：

- **入场区间 + 理想入场价**（按区间相对位置决定：区间下部直接分批买、中部等回踩、上部等更深回踩、突破后等回抽）
- **止损**：优先挂在结构位（区间下沿 / Spring 低点 / 突破位），结构位离入场过近时改用 4% 固定止损，过远（>12%）时给出风险警示
- **目标位**：区间上沿 → 近期高点延伸 → 因果量度目标（按横盘时长换算，标注「乐观」）
- **风险收益比**、**仓位建议**（按单笔风险不超过总资金 2% 反推仓位上限）
- **操作检查清单**（10 项：结构、事件、新鲜度、量价、日线、周线、位置、止损空间、风险收益比、大盘）
- **风险提示**和**判断失效条件**

内置的几条纪律（避免给出危险建议）：

- 结构不明（Unknown）时**不给**买卖动作，只提示观察
- 震荡区间中部且近 8 根K线无新信号 → 拦截追价，改为「等回落到区间下部」
- 风险收益比低于 1.5 → 降级为观望
- 检查清单 ≥4 项不通过 → 降级为观望/持有观察，并压低置信度
- 涨停/跌停、ST、次新股、疑似停牌、指数 → 分别给出对应提示

## 四、数据源说明

| 数据源 | 协议 | 提供内容 | 备注 |
| --- | --- | --- | --- |
| 东方财富 | https | 快照、日/周/月K线、分钟线 | 主源，字段最全（含换手、量比、市值） |
| 腾讯财经 | http | 快照、日/周K线、5~60分钟线、指数 | 备源，也是最稳的 http 源 |
| 新浪财经 | http | 快照、5~60分钟线、指数 | 第二备源 |

- 请求策略：**先 https，失败自动降级 http**，再换下一个数据源；任一成功即返回。
  某个主机的 https 一旦失败，会在 10 分钟内直接走 http，避免每次取数都白等一次超时。
- 若你的网络只允许 http（或中间设备会掐断 TLS），可加 `--http-only`
  或设置环境变量 `WYCKOFF_FORCE_HTTP=1`。
- 整次取数有时间预算（默认 45 秒，环境变量 `WYCKOFF_BUDGET` 可调）：
  核心的快照与日K线一定取；网络抖动导致超时时，会跳过周线/分时/大盘并在报告里注明，
  不会出现长时间卡住。正常情况下一次分析 1~3 秒，报告里会显示实际耗时。
- 复权：默认前复权（最新价与真实价格一致）；若长周期前复权出现非正价格（高分红个股），
  会自动改用后复权并在报告里说明。
- 报告底部会如实标注本次数据实际来自哪个源。

## 六、常见问题

**Q：提示「分析失败：…」怎么办？**
先确认代码写法（`600519` / `sh600519` / `600519.SH` 都可以），再试 `--http-only`，
最后用 `python tests/smoke_datasource.py` 看具体是哪个源不通。

**Q：`000001` 是平安银行还是上证指数？**
默认按**个股**处理（平安银行，深市）。要看上证指数请写 `sh000001`。

**Q：结论和市面上的软件不一致？**
威科夫是「结构 + 量价」的主观性方法，本工具的规则是显式写死的（见 `analysis.py` / `events.py` / `decision.py`），
阈值都可以按自己的理解调整；它也**不是**预测模型，只是把复盘逻辑标准化，减少情绪化操作。

**Q：为什么有时给「观望等待」而不是直接买？**
因为威科夫的纪律是「在结构支撑附近、有确认信号时买」，而不是在震荡中部追价。
出现观望时报告里会写清楚：等回落到哪个区间、或等什么信号出现再动手。
